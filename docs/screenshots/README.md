# Cerebro Portfolio Screenshots (Guideline for Humans)

To prevent visual fabrication, screenshots are deferred until a live container runtime is available to capture authentic visual assets. The following layout resolutions are recommended for final portfolio documentation:

## Recommended Visual Assets

### 1. Landing Page Workspace (`landing_page.png`)
- **Resolution**: 1440x900 (Desktop)
- **Visuals**: Dark slate backdrop (`#0f172a`), premium glowing logo, description hero text, animated gradient accents, and the "Secure Login / Register" portal showing standard OAuth / Email authentication forms.

### 2. Main Workspace UI (`workspace_desktop.png`)
- **Resolution**: 1440x900 (Desktop)
- **Visuals**: Tabbed layout showing active repository list in left drawer, code search query input in main area, a grounded explanation response card with source code syntax highlighting, and the citation badge linking to source modules.

### 3. Citations & Evidence Panel (`citations_evidence.png`)
- **Resolution**: 768x1024 (iPad/Tablet)
- **Visuals**: Expanded citation drawer displaying retrieval timing metadata (e.g. `245ms`), matching score confidence levels, and exact repository lines referenced.

### 4. Codebase Knowledge Graph & Accessible Fallback (`knowledge_graph.png`)
- **Resolution**: 1024x768 (Desktop)
- **Visuals**: Interactive Cytoscape force-directed network showing module link relationships, with the adjacent keyboard-accessible semantic `<table>` rendering repository file metrics.

### 5. Responsive Workspace (`workspace_mobile.png`)
- **Resolution**: 375x812 (iPhone Mobile)
- **Visuals**: Drawer collapse states, compact workspace headings, and fluid mobile button targets showing no content overflow or visual clipping.
